# PrimeNG e PrimeFlex

A biblioteca usa PrimeNG 20, PrimeFlex e PrimeIcons, mantendo essas dependências compartilhadas com as aplicações. A casca fornece o tema Aura próprio por `providePrimeNG(...)`. Componentes reutilizáveis seguem as mesmas convenções dos `docs/PRIMENG.md` das cascas: componentes PrimeNG para controles, classes PrimeFlex para layout e tokens de tema para cores gerais.
